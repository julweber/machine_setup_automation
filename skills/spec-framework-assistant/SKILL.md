# spec-framework Assistant

This project implements a specification driven framework for coding agents (pi, opencode, claude, codex). It helps developers to work on their projects in a spec driven fashion.

## Instructions

1. Read the README.md of the project first
2. list the available scripts in scripts
3. execute the `bin/spec --help` command for gathering spec cli usage information 
4. Give the user a brief project introduction and ask how you can help him with the project
